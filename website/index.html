以下為固定的操作示意，不會呼叫真實翻譯 API。實際結果會依你選擇的 provider 與網路狀況而定。

01

開啟 Translator

在 Windows Command Palette 搜尋並執行 Translator。

02

輸入要翻譯的文字

直接輸入，例如 hello world。若未指定語言，會使用已設定的目標語言。

03

指定目標語言，或直接複製

輸入 hello world >> ja 指定日文；在結果上執行 Copy 即可帶走翻譯。

GOOD TO KNOW

常見問題

需要網路連線嗎？

需要。翻譯請求會透過網路送至所選的第三方翻譯服務；應用程式具備 internetClient 能力。

翻譯結果來自哪裡？

目前程式內建 Bing、Google 與 Aliyun 三個 provider，預設使用 Bing，可在 Preferred provider 設定中選擇。

可以設定預設語言嗎？

可以。在翻譯頁面的 Target language 開啟語言設定並選取語言。內建語言包含 English、繁體中文、簡體中文、日文、韓文、法文、德文等。

我的文字會被儲存嗎？

依隱私權文件，應用程式與開發者不保留文字輸入或翻譯結果；翻譯時，文字與語言代碼會直接傳送給你選擇的第三方服務。
